# Logos Programming Language

#### Hello world
```
main() {
    print("Hello world")
}
```

#### Assignment
```
main() {
    x = 3
    y = 4
    z = x + y
    print(z)
}
```

#### Conditional
```
main() {
    x = 3
    y = 4
    if x > y {
        print("x is greater than y")
    } else x < y {
        print("x is less than y")
    } else {
        print("x is equal to y")
    }
}
```

#### Iteration
### Range Loop
```
main() {
    for i 0..10 {
        print(i)
    }
}
```
